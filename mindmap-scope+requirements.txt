******* MINDMAP EXPLAINED *********
Let's say I need to remember that I have work calls today at 10 AM, 11 AM and 2 PM.
My mindmap would look like this:
David  ->  Work -> Calls -> 10 AM -> 11 AM -> 2 PM

At the start of each day I look at my work calendar and fill out my mind map for the day. 

My mindmap might also  have something like
David -> Logan -> Meds -> 8 AM

By linking every task back to me through things like Logan or Work I am maintaing the connection of the task to me. Something I do that isn't good is that I can literally lose myself in a task, the mindmap helps me find my way back to me.

*********MINDMAP REQUIREMENTS**********
1. every mindmap should have today's date at the top like this: Thursday, July 23rd 2026
2. every mindmap should start with David in the center, DAVID is BLUE
3. every mindmap should have a node to the right for UD, UD is GREEN
4. every mindmap should have a node to the left for EM, EM is RED
5. every mindmap should have a node to the bottom for LOGAN, LOGAN is PINK
6. every mindmap should have a node to the top for WORK is YELLOW
7. every mindmap should hae a node to the top for WELLBEING is PURPLE
8. every mindmap node is text inside of an oval
9. the mindmap ui is written in javascript and html
10. the mindmap is mostly just a series of interconnected ovals with text
11. when a node is added it most always be further from David than the node that it came from
12. assume that 4 nodes outward in the work direction will be added immediately so the user should be able to add those without changing zoom or scrolling
13. the lines between nodes should not be so long that a lot of space is wasted
14. nodes should never overlap eachother
15. when you click a node, 3 options are displayed - rename node, add node, delete node
16. Adding a node should always be further outward, and it must stay visually aligned with the branch it came from — a child added to a node (e.g. WORK) should read as clearly part of that branch, not drift toward the center or another branch's direction. Concretely: when fanning out multiple siblings from the same parent, cap the angular rotation to roughly ±40° from the parent's own outward direction from David. Once that cap is reached, additional siblings should be pushed further outward (ringed farther out) rather than rotated past the cap.
